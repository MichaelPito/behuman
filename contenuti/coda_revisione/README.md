# Coda di revisione

Proposte automatiche (`python -m memoria.revisione.estrai`) e segnalazioni da verificare.
Nulla di questa cartella viene pubblicato. Per pubblicare una voce: verificarla secondo
`docs/02-metodologia.md` §3, spostarla in `../dichiarazioni/<slug>.yaml` con `stato: verificata`
e i due revisori, e aprire una pull request.
